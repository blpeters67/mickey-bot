# Voice DJ command coverage

173 commands: **72 by voice**, 101 typed-only.

By voice, a command runs through the same code as typed — the shared queue operations (core/queue_ops.py) or the command itself, invoked as the speaker with its own checks (permissions, cooldowns, consent). Ones that ask first (stop, clear, a very loud volume) still wait for a spoken yes. Typed-only commands are named to the planner, so asking for one by voice gets the reason instead of a pretend success.

Generated by `scripts/voice_coverage.py` from `core/voice_tools.py`.

## Voice-only operations

Operations with no single typed command behind them:

| Operation | What it does |
|---|---|
| `find_song` | ONE particular song they describe but don't name, when you aren't sure which it is ("that Yung Gravy song that samples Panic! At The Disco"): value = what to look up, artist if known. when as add_song. Never for "some songs" or "random songs" — you pick those yourself as add_song steps. |
| `add_album` | songs from one album: album = its title, artist, tracks = which ones: "all", "1-3", "7, 9", "first 3", "last 2", "random 3", "first half", "second half", "all except last", "all except 2, 5", "first 7 except 6", "first half except last" (numbers are album track numbers; first/last/halves after except count within what's being trimmed). count = how many times; when as add_song. |
| `add_top` | artist, count = how many (default 5). |
| `add_latest` | artist, count = how many (default 1). For "new"/"latest" songs you may not know. |
| `restart` | this song from the start. |
| `answer` | value = your spoken answer to anything else they asked (one to three short sentences). Facts about the queue and the music come from the state shown below — or use now_playing / queue_info, which read it live. |
| `typed_only` | they asked for something that has to be typed (see the typed-only list below): value = the command's name. I tell them how instead of doing nothing. |
