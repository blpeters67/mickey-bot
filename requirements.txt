# Optional — enables -karaoke (real AI vocal removal, not the old channel-
# cancellation filter). Pulls torch + onnxruntime (several hundred MB) and
# downloads a separation model (~100-500 MB) on first use.
#
# On a CPU-only host separation runs at roughly realtime or slower, which is
# why `karaoke` hands back a *file* instead of swapping the audio into live
# playback — a track finishes long before its instrumental is ready. Results
# are cached in ./stem_cache (STEM_CACHE_DIR, capped by STEM_CACHE_MB, default
# 2048); budget ~6 MB per track at the default STEM_BITRATE of 192k, chosen so
# a typical song fits Discord's 10 MB attachment limit.
# SEPARATION_MODEL picks the quality/speed trade-off:
# `fast` (default, the only sensible choice without a GPU), `good`, or `best`.
#
#   ./install.sh --karaoke          # CPU build
#   ./install.sh --karaoke --gpu    # CUDA build
#
# audio-separator>=0.24

# Optional (./install.sh --rembg) — enables -nobg (AI background removal). Downloads a ~180 MB
# U²-Net model on first use and wants ~1 GB RAM while running.
# rembg>=2.0.50
# onnxruntime>=1.16.0

# Optional (installed by default; ./install.sh --qr) — enables -qr.
# Tiny, pure-pip, no system libraries.
# `qrcode` generates, `zxing-cpp` reads (and handles barcodes too).
# qrcode>=7.4
# zxing-cpp>=2.2.0

# Optional (./install.sh --translate) — enables -translate, running
# locally with no API key.
# argostranslate is a heavy install (it pulls ctranslate2 and torch), and each
# language pair is a further ~100 MB downloaded on demand via
# `-translate install <from> <to>`. langdetect is tiny and identifies the
# source language; without it you'll be asked to name it.
